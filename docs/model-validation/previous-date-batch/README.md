# Superseded reports

These reports preserve the previous task's measurements without treating them as current validation. Date-batch freezing did not embargo results from tournaments that started earlier but overlapped a later event. Year-end labels could also become available after the next partition began. The current pipeline uses a conservative 21-day result delay plus label-availability boundaries. Use the reports one directory above for current measured results; do not cite the earlier figures as the corrected engine's accuracy.
